# SimplePrompt

**A Simple Prompt Tool for Beginners**

A beginner-friendly AI image prompt builder with a clean, intuitive UI.
Explore bilingual tags, mix and match ideas, and generate prompts with ease.

面向 AI 生图新手的提示词工具，提供干净易用的界面。支持手机和桌面、中英标签搜索、自由搭配、收藏、黑名单，以及保留已选词的种子随机生成。

## 使用

直接用浏览器打开 `index.html`，无需安装依赖。也可以通过 GitHub Pages 使用。
收藏、黑名单、搭配与设置保存在使用者自己的浏览器，不会上传到仓库或服务器。

也可直接访问连接 https://alexzba.github.io/SimplePrompt/ 使用

## Language / 界面语言

The first visit follows the browser's preferred system language: Chinese (`zh-*`) uses the Chinese UI; English and other languages use English. Switch with **English / 中文** next to **About SimplePrompt**. On phones, both are in **More**. Your manual preference is remembered in this browser.

首次打开按浏览器提供的首选语言显示中英文界面。可在“关于 SimplePrompt”旁切换，手机端入口位于“更多”菜单。手动选择会保存；切换不会改变搭配、收藏、黑名单或随机种子。两种界面均支持中英搜索，复制结果仍为英文 tag。
